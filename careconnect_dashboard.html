System Information

Prototype scope and integration status

Included in this demo

  • Four bed-wise patient profiles and vital sign sample values
  • Search/filter, patient detail view, nurse call workflow
  • Tamil/English voice command simulation, with browser speech-recognition option
  • Example early-warning thresholds, bed-exit simulation, sensor/offline/battery warnings
  • CSV export and browser print-to-PDF

Requires hardware/backend integration

  • ESP32 and actual sensors
  • Validated measurement devices for temperature, BP, respiratory rate, and SpO₂
  • Real-time database, secure API, persistent storage, and actual notifications
  • Automatic timed escalation, bed sensor, battery feedback, and two-way audio
