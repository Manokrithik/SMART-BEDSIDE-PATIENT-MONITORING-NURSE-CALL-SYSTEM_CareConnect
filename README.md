2. Project Title

SMART BEDSIDE PATIENT MONITORING & NURSE CALL SYSTEM

3. Problem Statement

In hospitals, patients may need assistance with drinking water, pain, movement, toilet access, or other basic needs. Communicating these needs quickly and tracking nurse responses can be challenging. This project aims to improve patient-nurse communication through a smart bedside monitoring and nurse-call system.

4. Healthcare Use Case

The system allows patients to request assistance through a touchscreen interface or call button. Nurses can view and acknowledge requests through a dashboard. The system also demonstrates vital-sign displays, nurse-call status tracking, simulated bed-exit alerts, sensor-fault notifications, low-battery alerts, and digital reports.

5. Technical Stack

Frontend: HTML, CSS, JavaScript
Microcontroller: ESP32 for planned hardware integration
Pulse and SpO₂ Sensor: MAX30102 
Other Vital Signs: Suitable sensors are required for temperature, blood pressure, and respiratory rate
Alert System: Rule-based demonstration alerts
Reporting: CSV export and browser-based PDF printing
Interface: Web-based monitoring dashboard

AI/ML Model Details

The current prototype does not include a trained AI/ML model. It demonstrates rule-based alerts using example conditions. Future development may explore machine learning for vital-sign trend analysis after collecting suitable data and validating the model.

8. System Architecture

The proposed system consists of the following components:

1. Patient interface with touchscreen and call button.
2. Optional sensors for vital-sign measurements.
3. ESP32 microcontroller for planned hardware integration.
4. Web dashboard for displaying readings and nurse-call requests.
5. Alert module for simulated warnings and request escalation.
6. Report module for exporting monitoring data.

9. Project Outcomes

* Demonstrates a digital patient-to-nurse communication workflow.
* Displays sample heart rate, SpO₂, temperature, blood pressure, and respiratory rate.
* Demonstrates nurse-call acknowledgement and escalation concepts.
* Simulates bed-exit, sensor-fault, and low-battery alerts.
* Supports digital report generation for demonstration purposes.
* Provides a foundation for future IoT-based healthcare assistance.

10. Future Scope

* Integrate and test real sensors with the ESP32.
* Implement reliable local alarms and nurse-station notifications.
* Add secure patient-data storage and access control.
* Improve voice interaction and two-way communication.
* Validate sensor accuracy and system reliability.
* Conduct usability, privacy, and safety testing before any real-world clinical use.

11. Conclusion

The Smart Bedside Patient Monitoring & Nurse Call System is an educational prototype designed to improve communication between patients and nurses. By combining a web dashboard, nurse-call workflow, sample vital-sign displays, and simulated alerts, the project demonstrates how technology can support patient assistance and caregiver response tracking.
